# Sound credits (0 to 1, portrait film)

`film.wav` is built by `scripts/build-sfx.py` from the sources in `src/`, the music bed in
`../bgm/warm.wav`, and sounds synthesised in that script (clock tick, odometer ticks and whirr,
landing clunk, card thumps, pen strokes, handwriting, marker squeak, paper slides and crumple,
page flips, note slaps, split-flap clacks, mallet notes, drone, projector whirr, room tone).
The synthesised parts use a seeded generator, so the stem rebuilds identically.
